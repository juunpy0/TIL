# 아키텍처 패턴
아키텍처 패턴은 시스템 구성 요소 간의 구조와 상호작용을 정의하는 설계 방식이다.
구성 요소를 조직하고 그 역할과 관계를 명확히 하여 시스템 전체 구조를 확립한다.

또한, 개발 과정에서 전체적인 구조를 기반으로 어떤 방식으로 기능을 분리하고 계층을 나눌지에 대한 기준이기도 한다. 
__예를 들어 View, Model, ViewModel과 같이 역할을 분리하거나, 데이터 흐름과 책임 범위를 정의하는 등의 의사결정이 이에 해당한다.__

즉, 세부적인 구현 단계에서는 클래스 이름, 파일 위치, 패키지 구성 등의 구체적인 설계가 이루어지는 기초 공사(솔루션) 단계이다.
